SIMOBILE

Sistem Informasi Mobile Toko Makmur Jaya

Tentang SIMOBILE

SIMOBILE merupakan aplikasi mobile sederhana untuk membantu pengelolaan operasional Toko Makmur Jaya.

Pengelolaan Produk

Aplikasi menyediakan fitur untuk melihat, menambah, mengedit, dan mencari data produk beserta harga dan stoknya.

Keranjang dan Transaksi

Produk dapat ditambahkan ke keranjang, dihitung total belanjanya, kemudian dikonfirmasi menjadi transaksi.

Riwayat Transaksi

Setiap transaksi yang dikonfirmasi dapat dilihat kembali melalui halaman Riwayat Transaksi beserta detailnya.

Dashboard

Dashboard menampilkan jumlah produk, total transaksi hari ini, total pendapatan hari ini, dan produk terlaris.

Penyimpanan Data

Data SIMOBILE disimpan sementara di dalam aplikasi tanpa menggunakan database eksternal maupun API.

Tampilan

SIMOBILE menggunakan custom theme serta menyediakan pilihan Mode Terang dan Mode Gelap.
